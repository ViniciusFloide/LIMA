A Propriedade position do CSS pode assumir os seguntes valores

  • Static - Este é um valor padrão. O elemento é posicionado de acordo com o fluxo normal do documento.
  • Relative - O elemento é posicionado em relação a sua posição no fluxo normal do documento.
  • Fixed - O elemento é posicionado em relação ao viewport.
  • Absolute - O elemento é posicionado em relação ao ancestral mais próximo.
  • Stick - O elemento varia entre relative e fixed dependendo da posição da rolage.

A posição é definida pelas propriedade top, buttom, left, right
